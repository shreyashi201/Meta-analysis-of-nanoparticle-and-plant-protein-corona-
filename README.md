# Meta-Analysis-and-Machine-Learning-of-Nanoparticle-Plant-Protein-Corona
Computational analysis, meta-analysis, and machine learning of nanoparticle–plant protein corona interactions, including proteomic data processing, classification, and identification of discriminatory proteins.

This repository provides the original R scripts, datasets, computational workflows, and analytical outputs associated with the research project entitled "Meta-Analysis of Nanoparticle and Plant Protein Corona."

The project aims to understand nanoparticle–protein corona interactions in plant systems through systematic literature-based meta-analysis, comparative proteomic analysis, and machine learning approaches.

The computational workflow incorporates three machine learning algorithms: Light Gradient Boosting Machine (LightGBM), Random Forest (RF), and Support Vector Machine (SVM) to classify nanoparticle–protein corona profiles, evaluate model performance, and identify proteins contributing to discrimination among experimental groups.

This repository is intended to promote transparency, reproducibility, and further research in the emerging field of nanoparticle–plant interactions and plant nanoproteomics.
